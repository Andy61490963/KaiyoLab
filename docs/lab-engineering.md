# LAB 互動實驗與前端工具

LAB 讓一般訪客先玩出效果，再依需要展開前端工具的參數與輸出，沿用網站的 Astro、React、TypeScript、SVG 與 Canvas，不增加動畫或圖形套件

入口與公開網站共用導覽、明暗配色與中英文切換，沿用單欄列表與網站外框，以實際效果預覽搭配一句玩法，依粒子、SVG、立體畫廊、動畫及版面順序展示；有已發布內容時，下方才顯示「站長作品」，管理者可以繼續發布自己的實驗與工具

每個實驗先呈現操作畫面與基本控制，精確參數、效能數值與程式碼收在「進階設定與匯出」，技術標籤和原理則移到「看看怎麼做的」，皆為可用鍵盤操作的原生 `details`，收合不會重設參數或輸出內容

粒子提供三組外觀預設與換一張，輪播提供平面、立體及傾斜視角；SVG 可直接換形狀、改色與下載，動畫可選動作觀看，Grid 可挑版型、拖拉並切換裝置寬度

站長作品使用共用搜尋與排序工具列，固定每頁 12 筆，沒有內容時不顯示空區塊，搜尋無結果時保留查詢及清除入口，操作方式見[搜尋、排序與分頁](list-pagination.md)

## 輸出界線

### 動態曲線

預覽先求解 Bézier 曲線的時間座標，再計算輸出值，避免把參數時間直接當成 CSS easing 的時間

控制點的 x 範圍為 0–1，y 範圍為 −0.5–1.5，可製作預備動作與過衝；透明度遵循 CSS 的 0–1 範圍，位移與縮放保留曲線的過衝

複製的 CSS 包含一段位移動畫、可調整的 `--travel` 與 `prefers-reduced-motion` 規則，可將 easing 與時間套用到自己的其他屬性

### Grid 排版

預覽使用實際 CSS Grid，拖曳及位置欄位修改同一份行列座標，超出範圍時會限制在目前格線內

區塊可刻意重疊，工具會顯示提示並保留輸出結果，後面的區塊繪製在上層，透過「選取區塊」仍能編輯被遮住的項目

輸出包含 520px 容器查詢，依元件容器的實際寬度切換成單欄，不需要 JavaScript；區塊文字經 HTML 跳脫，CSS class 使用固定索引，避免標籤被當成標記執行

### SVG 形狀

相同種子、節點數與不規則程度會產生相同的徑向輪廓，A／B 維持相同的 cubic 路徑命令數，變形時逐段插值起點、控制點及終點

手動節點與 Bézier 控制柄都限制在畫布範圍內，替描邊保留餘裕；任意拖拉可能形成交叉輪廓，工具會依 SVG 預設填色規則呈現

下載的是當下的靜態形狀，不包含編輯節點、虛線參考、動畫或外部資源，適合放入 `img`、CSS 背景或內嵌 SVG

匯出只接受有限數值與六位十六進位色碼，填色也可選 `none`，不將自由文字拼入 SVG 屬性；播放時先暫停，再複製或下載目前畫面

### 3D 輪播

位置保留無界連續座標，畫面以週期最短距離映射，最後一張與第一張共用相同慣性與彈簧規則

匯出包含外觀參數與 `renderCarousel()`，**它是繪製函式，不是附完整手勢、DOM 與導覽的輪播元件**，宿主需提供卡片結構、尺寸、位置／速度、拖曳與生命週期

預覽中的手機模糊量有額外上限，匯出函式提供可調整的模糊設定，整合到其他專案時可自行加上裝置策略

### 粒子背景

粒子沿多尺度勢函數的解析 curl 場移動，指標額外加入吸引或排斥，使用固定 1/120 秒步長推進

PNG 是下載瞬間的 Canvas 畫面，尺寸依目前畫布與像素比決定，包含目前主題的背景色，**不是透明圖、動畫或影片**

JSON 保存種子、粒子上限、速度、配色、作用力方向與積分步長，**不含完整 runtime，也不是目前粒子位置的可恢復快照**；要在自己的網站重現動態背景，需整合流場模型及 Canvas 繪製生命週期

## 模組責任與生命週期

- 純運算位於 `src/lib/lab`，包括 easing 反解、Grid 幾何、SVG 曲線、彈簧及流場
- `LabPreview.astro` 以同一組幾何、預設及專案素材產生入口 SVG／CSS 預覽，不啟動五個工具的 React island；預覽為裝飾，整列連結提供清楚名稱與鍵盤焦點
- 入口只在停留或聚焦時播放有限次的 CSS 示範，減少動態模式保持靜態，無 JavaScript 時仍有完整預覽及可用連結
- `src/components/lab` 處理控制、預覽與匯出，Astro 路由共用 `LabLayout`，每個路由只載入自己的 React island
- `useLabEnvironment` 統一讀取語言、主題、減少動態與分頁可見性
- SVG 變形預覽最多每秒更新 30 次，預設不自動播放，隱藏分頁或啟用減少動態時停播
- 輪播與粒子在離開可視區時停止背景動畫，輪播收斂後停止逐幀更新，粒子以有界累積器處理固定步長
- 粒子桌面上限為 1,100，窄版畫布最多 480，Canvas 像素比上限為 2
- 下載使用瀏覽器本機輸出，Blob URL、observer、timer、事件監聽與動畫迴圈皆在結束時清理
- 剪貼簿被瀏覽器拒絕時提供錯誤回饋與可選取原始碼，非同步複製結果不能把已變更的輸出誤標為已複製

## 驗證方式

在已設定本機開發資料庫的環境執行，整站 E2E 會建立測試內容，請使用獨立測試資料庫

```bash
npm run check
npm test -- --maxWorkers=2
npm run test:integration
npm run build
npm run test:e2e
```

| 範圍         | 驗證項目                                                    | 主要測試位置                                                             |
| ------------ | ----------------------------------------------------------- | ------------------------------------------------------------------------ |
| 曲線         | 線性與預設 easing、反解誤差、非法輸入、匯出 CSS、拖曳與鍵盤 | `tests/lab-motion-studio.test.ts`、`tests/e2e/lab-motion-studio.spec.ts` |
| Grid         | 位置限制、跨度、重疊、標籤跳脫、響應式輸出與預覽一致        | `tests/lab-grid-studio.test.ts`、`tests/e2e/lab-grid-studio.spec.ts`     |
| SVG          | 種子重現、閉合 cubic、插值連續、輸出驗證、拖曳／觸控／下載  | `tests/lab-svg-studio.test.ts`、`tests/e2e/lab-svg-studio.spec.ts`       |
| 輪播與粒子   | 週期座標、彈簧、固定步長、種子、鍵盤、觸控、失敗處理與匯出  | `tests/lab-motion.test.ts`、`tests/e2e/lab-motion.spec.ts`               |
| 版面         | 七種寬度、明暗、中英文、焦點、減少動態、頁面返回            | LAB 瀏覽器測試與實際截圖                                                 |
| 一般訪客入口 | 成果預覽、玩法順序、基本操作、預設收合、進階功能與鍵盤展開  | `lab-playful-*.spec.ts` 與各工具既有回歸                                 |

視覺驗收尺寸涵蓋 1920、1440、1280、1024、768、430、390、375px，除了沒有水平溢出，還需確認控制點、輸入欄位、預覽與原始碼在窄版可操作

文章、作品列表與內頁共用 1480px 網站外框、1020px 內容區及相同左側導覽寬度，桌面內容與頁尾靠左對齊，只保留最大 56px 內距，不在剩餘空間再次置中；閱讀欄寬度不變，文章在內容區內安排正文與 232px 目錄側欄，目錄與相關文章仍一起固定

回歸測試逐一比較進入文章／作品前後及返回列表時的外框、內容起點、側欄和語言切換位置，確認桌面側欄間距沒有疊加置中留白，另驗證目錄點擊、文章底界與手機折疊目錄

程式測試與瀏覽器驗證的最新結果請以本次 PR 與 GitHub Actions 記錄為準，舊版實驗的測試數字和效能量測不適用於這批工具
