# 內容匯出與匯入

後台的 **Content transfer**（`/admin/transfer`）提供 KaiyoLab 站台之間的內容搬移，沿用原有後台側欄、面板與明暗配色

## 匯出內容

按 **Download archive** 下載 `.kaiyo.json.gz` 檔案，封存格式為 gzip 壓縮的 JSON，內含：

- 文章與作品的草稿、公開快照及垃圾桶內容
- 版本紀錄，以及系列、順序和封面焦點資料
- 分類與標籤
- 網站名稱、首頁 Markdown、關於我、品牌圖片引用及社群連結
- 媒體庫的 WebP 圖片、替代文字及尺寸，圖片以 Base64 存入同一檔案

不包含站長帳號、密碼雜湊、登入 Session、驗證密鑰、資料庫連線、站點 URL 或舊網址轉址表

封存檔包含未發布內容與私人圖片，請存放在可信任的位置，不要提交到公開 Git 倉庫

這是內容搬移工具，不是完整系統備份；若需保留登入、發布狀態、網址轉址與部署密鑰，請使用 README 的資料庫與 volumes 備份流程

## 匯入流程

1. 在目的站開啟 **Content transfer**，選擇封存檔
2. 預設保留目的站網站設定；若需要一起搬移首頁、品牌與關於我，明確勾選 **Also apply site settings and About me content**
3. 按 **Check archive**，檢查新增文章、作品、圖片、分類、標籤及歷史數量
4. 查看 **Names and URLs** 的調整清單，再按 **Import as private drafts**
5. 到文章與作品編輯器檢查內容，逐篇決定是否發布

所有匯入文章與作品均建立新 UUID 並成為私人草稿，包括原先已發布或在垃圾桶內的項目，不會覆蓋或刪除目的站的既有內容

來源的公開版本保存在版本紀錄，並不立即對外發布；既有歷史版本也會保留，圖片取得新 UUID，Markdown、封面、設定和歷史紀錄中的 `/media/…webp` 引用會改成新圖片網址

當文章網址或歷史保留網址衝突時，新增 `-import-1` 等後綴，所有匯入歷史版本也會改用這個新網址，確保日後還原不會接管其他文章；相同分類或標籤名稱共用既有項目，分類網址衝突則調整新項目的網址並在確認前顯示

每篇文章會額外保存匯入當時的草稿快照，並保留最近 99 筆非公開歷史，加上新快照合計最多 100 筆；公開版本永久保留，超過草稿保留上限時會在確認畫面列出省略筆數

勾選套用設定時，確認匯入後首頁介紹、關於我及品牌設定會立即套用；目的站 URL 與站長帳號保持不變，勾選前請確認這是預期行為

封存檔內的一般文章連結不會自動改寫，尤其網址產生匯入後綴時，請在發布前檢查站內連結

## 限制與失敗處理

| 項目        | 限制                   |
| ----------- | ---------------------- |
| 壓縮檔      | 32 MiB                 |
| 解壓後 JSON | 64 MiB                 |
| 文章與作品  | 合計 2,000 筆          |
| 歷史版本    | 10,000 筆              |
| 分類與標籤  | 合計 2,000 筆          |
| 圖片        | 500 張                 |
| 個別圖片    | 10 MiB、最長邊 2,400px |
| 圖片總量    | 30 MiB                 |

匯入只接受本系統的 WebP 圖片，會實際解碼、確認格式與尺寸，拒絕動態、損壞或超出限制的影像；不接受檔案路徑指定，也不從外部網址下載任何檔案

伺服器在寫入前重新檢查封存檔與目的站狀態，並使用資料庫交易及內容鎖定；若有人在確認後修改內容，會要求重新檢查封存檔，避免沿用過期結果

圖片先寫入暫存目錄，交易期間移到新 UUID 路徑；正常錯誤與資料庫提交失敗會回滾資料並移除本次圖片，不留下半套匯入內容。若提交回應遺失，會重新查證資料庫，只清理確定沒有引用的新圖片；資料庫無法確認時保留圖片，避免刪掉其實已成功匯入的內容。若程序或主機在提交瞬間突然中止，可能留下未被資料庫引用的暫存或孤立圖片，需要由維運人員在備份後檢查，既有圖片不會被覆寫

超過可攜封存限制的站台，請改用資料庫與 uploads volume 備份還原；合併到已有內容的站台後，總量仍受匯出限制約束

## 驗證方式

```bash
npx vitest run tests/portability.test.ts
# 設定測試 PostgreSQL 的 DATABASE_URL 後執行，測試會建立並刪除自己的隨機資料庫
npx vitest run tests/integration/portability.test.ts
```

單元測試涵蓋壓縮限制、解壓炸彈、型別與欄位白名單、路徑注入、遺失媒體及偽裝影像；真實 PostgreSQL 測試驗證匯出再匯入、私人草稿隔離、歷史與圖片引用、目的站 URL、網址衝突、並行重送、提交失敗回滾，以及匿名或跨站請求被拒絕
