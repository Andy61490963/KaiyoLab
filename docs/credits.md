# 素材與第三方授權

KaiyoLab 程式碼採用專案根目錄的 [MIT 授權](../LICENSE)。以下第三方套件與字體適用各自的授權，實際版本以 `package-lock.json` 為準。

| 項目                                 | 用途                   | 授權／來源                                        |
| ------------------------------------ | ---------------------- | ------------------------------------------------- |
| Noto Sans TC                         | 中文介面與閱讀字體     | SIL Open Font License 1.1，由 Fontsource 套件提供 |
| Space Grotesk                        | 品牌與短標籤字體       | SIL Open Font License 1.1，由 Fontsource 套件提供 |
| JetBrains Mono                       | 程式碼字體             | SIL Open Font License 1.1，由 Fontsource 套件提供 |
| Lucide                               | 介面圖示               | ISC 授權                                          |
| Astro、React、Tailwind CSS、Radix UI | 網站與互動介面         | 各套件的 MIT 授權                                 |
| CodeMirror、remark／rehype、Shiki    | 編輯器及 Markdown 渲染 | 各套件的 MIT 授權                                 |
| Better Auth、Drizzle ORM             | 驗證及資料存取         | 各套件的 MIT 授權                                 |
| PostgreSQL                           | 資料庫                 | PostgreSQL License                                |

字體由本地套件建置進網站，閱讀頁面不依賴第三方字體 CDN。發布程式碼與容器映像時請保留依賴套件附帶的 LICENSE 檔案。

## 設計參考與專案素材

目前公開網站的排版與色彩參考 [Tania Rascia 的作品頁](https://www.taniarascia.com/projects/)，採用奶油白／炭灰明暗主題、莓紅連結、桌面側欄與文字優先的作品卡。KaiyoLab 的介面自行實作，保留自己的品牌、內容管理功能與內容，未使用對方的文章、圖像或程式碼。

初版動漫科技風視覺曾參考 [cod-aquarium](https://github.com/Codfisher/cod-aquarium)，未將對方的品牌、文章或圖像納入本專案。初版插畫與品牌圖形為 KaiyoLab 製作；插畫目前不作為公開首頁的預設主視覺，相關生成方式與繁體中文設計描述保留於[視覺素材來源](assets.md)，供歷史素材來源查考。

站長可透過後台更換自己的品牌圖片與首頁插畫。使用或散布自行上傳的圖片前，請確認具有相應權利。
