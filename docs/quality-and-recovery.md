# 閱讀、內容品質與備份改善

這次沿用公開網站及後台的既有版型，保留目錄與推薦文章共用的固定側欄

## 已實作

- 網站設定及關於我帶版本號更新，多分頁衝突會保留本頁文字，可下載副本或明確重新載入
- 媒體上傳與內容匯入在資料庫提交結果不明時保留檔案，避免連線中斷導致資料庫有圖片但實體檔已被刪除
- 匯入時先建立所有文章、作品與舊網址的對照，再改寫 Markdown 站內連結，保留查詢字串及章節，預覽顯示變更
- 發布檢查新增 Mermaid 語法與本篇、其他公開文章的章節錨點提示
- 手機標籤可收合，保留已選條件，長標籤換行；搜尋支援多關鍵字 AND 及引號片語
- 首頁、文章清單與內頁共用閱讀時間，內容語言與介面語言分開
- 無封面的公開文章及作品產生 PNG 分享圖，使用隨附中文字型，補上文章結構化資料
- 分類與標籤新增、改名後定位到該項目，保留篩選及排序，刪除後校正頁碼
- Compose 每日完整備份、過期清理及失敗紀錄，後台顯示本機備份超時狀態
- 提供單節點 Kubernetes 的 systemd 備份範例與需自行設定目的地的加密異地副本
- Caddy 連線失敗時回傳 503、Retry-After 與簡短維護訊息，保留應用程式自己的錯誤狀態

## 驗證方式

`npm run check`、`npm test`、`npm run test:integration` 與 `npm run build` 檢查型別、核心規則、實際 PostgreSQL 資料流程及 SSR 建置

`npm run test:e2e` 使用專用 Chromium，覆蓋初始化、登入、文章及作品編輯、自動儲存、衝突、發布與下架、版本還原、垃圾桶、媒體與使用中圖片、分類標籤、設定、匯出匯入、系統狀態、主題語言、列表、目錄及流程圖，新增案例包含 375、768、1440px 與鍵盤操作

GitHub CI 另執行實際容器啟動、HTTPS 代理、Caddy 停機與恢復、備份子程序失敗、持鎖資料庫連線遭終止、Python 鎖確認、加密備份與錯誤密碼拒絕，以及備份還原至全新 volumes 後的登入與閱讀，相關腳本位於 `docs/operations/`

本機 Windows Docker Engine 未啟動，Docker 結果以對應提交的 CI 執行為準，不以 YAML 語法檢查當作部署成功

## 邊界

Zeabur 使用持久磁碟的單副本服務仍以 Recreate 更新，原生代理在切換期間可能回傳短暫 502，這次沒有強制共用磁碟或修改平台控制器，細節見[部署說明](zeabur.md)

異地副本需要站長選定儲存目的地及憑證，本機成功備份不等於異地已啟用，完整步驟見[備份與還原](backup-restore.md)

語言標記以中文／英文內容偵測，混合語言可能以主要語言呈現；分類很多時仍會佔用原有分類導覽空間，此次只收合手機的未選標籤
